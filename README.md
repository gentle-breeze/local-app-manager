# Local App Manager · 应用观测台

面向 macOS 的本机应用运行看板。只读观察优先，帮助查看已登记应用的端口、HTTP 可访问性、进程指标和最近日志。Python 标准库后端，原生 HTML/CSS/JavaScript 前端，无第三方运行依赖。

## 快速开始

需要 macOS 和 Python 3.9 或更新版本。

```sh
git clone https://github.com/gentle-breeze/local-app-manager.git
cd local-app-manager
python3 server.py
```

打开 **http://127.0.0.1:4320**。按 `Ctrl+C` 退出。可用 `--port 4321` 改端口；监听地址始终是 IPv4 loopback。请使用明确的 `127.0.0.1` 地址，不支持代理、公开部署或远程访问。

初次启动为空白看板。点击「添加应用」，填写名称和本机端口即可只读观察已有服务，无需修改代码。可选填写工作目录、HTTP 健康检查路径、明确指定的 `.log` 文件。端口 0 表示不探测。

## 状态如何解读

- 每 5 秒刷新。端口可达只表示 TCP 连接成功；HTTP 成功只表示入口可访问，业务健康仍标为未知。
- 未发现监听不代表应用已停止：它可能使用其他端口、非 TCP 通信或在另一台机器上运行。
- 只有监听进程工作目录与登记目录一致才展示 PID、运行时长、CPU 与 RSS 内存。这是单个监听进程的数据，不是整棵进程树。CPU 使用系统 `ps` 值，不是固定采样窗口的即时占用。
- 日志只显示明确指定文件的最后 16 KB，或本管理器启动进程的有限内存输出。没有日志不代表没有异常。日志弹窗是打开时的快照，重新打开可查看新内容。
- 设置中可修改目录、端口、HTTP 路径和日志路径。观察/受管模式创建后不能转换；需要受管时另建条目。第一版不提供删除条目、远程应用监控或自动扫描所有进程。

## 可选进程管理

添加应用时展开高级设置，允许管理器启动应用，填写工作目录和命令 JSON 数组。首项必须是可执行文件绝对路径，例如 `["/usr/bin/python3", "app.py"]`。程序以前台方式执行，不经 shell 解释。仅登记可信程序，不要在参数中填写密钥。

已有观察条目不允许启停。受管操作只作用于本管理器创建的子进程，不接管已存在进程；端口被占用时拒绝启动。对于端口 0 的应用，无法检测已有副本。

每个受管应用有独立 supervisor 和进程组。停止、重启、应用自然退出、管理器退出或控制管道断开时，先向本组发送 SIGTERM，1 秒后发送 SIGKILL。使用内存中的子进程句柄，不持久化 PID，也不根据历史 PID 发送信号。不支持自行 `setsid` 或脱离进程组的守护程序，请勿登记后台服务安装命令。

同一数据目录使用内核文件锁防止重复实例。默认配置保存在被 Git 忽略的 `.local/apps.json`，可通过 `--data-dir` 指定独立数据目录。

## 安全与限制

- 仅监听 loopback；不安装开机服务、不改防火墙、不创建长期凭据。
- HTTP 验证 Host；写请求要求匹配的 Origin、JSON 类型和每次启动随机会话令牌。不启用 CORS；CSP 限制外部资源与嵌入。
- 子进程仅继承 `HOME/PATH/LANG/TMPDIR`。应用可自行读取其既有安全配置，管理器不扫描环境文件或读取进程环境。
- 日志敏感行过滤属于启发式处理，不能保证发现所有秘密。不要登记含密钥的日志或将密钥写入命令。输出不另存磁盘；内存缓存最多 160 块，每块最多 2048 字节。
- 本机同账户程序和浏览器属于信任边界。本工具不是多用户权限隔离系统，也不应通过隧道或代理暴露。
- 仓库不包含实际应用登记、运行结果、截图或个人机器信息。测试生成的 `evidence/` 默认忽略，可能含本机临时路径，请不要公开提交。

## 构建和测试

```sh
python3 -m unittest -v test_manager.py
python3 build.py
# 可选前端语法检查，需要 Node.js
node --check web/app.js
```

构建产生独立 `dist/`，可用 `python3 dist/server.py` 启动。其默认数据目录为 `dist/.local`；需要共享配置时显式指定 `--data-dir`。

6 项集成测试使用临时目录和 loopback 合成服务，覆盖生命周期、重复实例、外部端口不接管、进程组清理、父管道断开、日志边界和 HTTP 请求防护。

可选无头浏览器验收需要 Node.js 22+ 和已安装的 macOS Google Chrome，不会自动下载软件：

```sh
node test_headless.mjs
```

测试使用独立临时 Chrome profile、空白临时登记和专用测试服务，覆盖宽屏/窄屏、添加/取消/重复保存、状态区别、日志显示与脱敏、受管进程启停和 JavaScript 异常检查。结束后清理临时实例与 profile；结果及截图保存在被忽略的 `evidence/`。不会连接桌面 Chrome 个人资料。无头测试不等于桌面浏览器验收。

仓库目前未配置 CI 工作流；请按上述命令在支持的本机环境验证。
